## 📌 Steps to Run the Graph Calculator Project

---

## **1. Install Visual Studio Code**

Download and install from:
👉 [https://code.visualstudio.com/](https://code.visualstudio.com/)

---

## **2. Download Anaconda**

a. Go to:
👉 [https://www.anaconda.com/download](https://www.anaconda.com/download)

b. Choose:

* Windows
* Python 3.x (64-bit)

---

## **3. Install Anaconda**

1. Run the installer

2. Click: Next → Next → I Agree

3. Select:

   * ✅ Just Me

4. Leave install location as default

5. Important:

   * ⛔ DO NOT check **“Add Anaconda to PATH”**
   * ✅ Check **“Register Anaconda as default Python”**

6. Click **Install**

---

## **4. Test Anaconda**

Open **Anaconda Prompt**, then type:

```bash
conda --version
python --version
```

✅ If both show versions → installation is working

---

## **5. Create a Project Folder**

Example:

```bash
C:\Users\yourusername\Python Workspace\python files\GraphCalculator
```

---

## **6. Create and Activate Environment**

a. Go to your folder:

```bash
cd C:\Users\yourusername\Python Workspace\python files\GraphCalculator
```

b. Create environment:

```bash
conda create -n graphcalc python=3.11
```

c. Activate it:

```bash
conda activate graphcalc
```

✅ You should now see:

```
(graphcalc) ...
```

---

## **7. Install Required Libraries**

Run **one by one**:

```bash
conda config --add channels conda-forge
conda config --set channel_priority strict
conda install matplotlib numpy ipywidgets jupyter nomkl
```

After install:

```bash
jupyter nbextension enable --py widgetsnbextension
```

---

## **8. Add Project Files**

Put your notebook file inside the folder:

```
GraphCalculator
│ notebook.ipynb
```

---

## **9. Open in VS Code**

In Anaconda Prompt:

```bash
code .
```

⚠️ If `code .` doesn’t work:

* Open VS Code manually
* Then open the folder

---

## **10. Run the Notebook**

Inside VS Code:

* Open `notebook.ipynb`
* Select Python kernel → choose **graphcalc**
* Install suggested extensions if prompted
* Run the notebook

---

# 🔥 Important Fixes I Added

* Removed quotes in paths (`"yourusername"` can break commands)
* Added fallback if `code .` fails (common issue)
* Clarified kernel selection (this confuses beginners a lot)

---

# 💡 Optional (better method – recommended)

Instead of Step 6–7, you can make it **1 command only**:

On your PC:

```bash
conda env export > environment.yml
```

Then your friend runs:

```bash
conda env create -f environment.yml
conda activate graphcalc
```

👉 This avoids installation errors completely.
